# LOGISTA OFC

Create a modern AI-powered logistics web platform for an industrial metal construction company named ERCM RED AND BLACK  AND HIS NAME LOGISTA

Update the logistics platform UI with the following modifications:

1. TOP NAVIGATION BAR

Replace the bottom navigation with a modern top navigation bar.

The top navbar must contain:

- Company logo on the left

- Dashboard

- Trucks

- Planning

- Suppliers

- Projects

- Map

- Analytics

- Notifications

- User profile

Design requirements:

- Sticky top navigation

- Glassmorphism effect

- Modern hover animations

- Active page indicator

- Professional industrial style

- Responsive behavior

- Elegant icons

- Dark modern theme

2. GOOGLE AUTHENTICATION

Add secure Google Sign-In authentication.

Features:

- “Continue with Google” login button

- Google OAuth authentication

- Secure session management

- Auto user profile creation

- User avatar after login

- Logout functionality

- Remember user session

3. LOGIN PAGE DESIGN

Create a premium login page with:

- Modern industrial background

- Animated gradient

- ERCM Logistics branding

- Minimal clean layout

- Glassmorphism login card

- Welcome text

- Smooth animations

The login page must contain:

- Login with Google button

- Company logo

- Short platform description

- Professional logistics illustration

4. USER PROFILE MENU

After login, display:

- User photo

- User name

- User role

- Settings

- Logout button

5. SECURITY

Implement:

- Protected routes

- Role-based access

- Secure authentication flow

- Session persistence

6. UX IMPROVEMENTS

- Smooth page transitions

- Loading animations during authentication

- Modern notification system

- Elegant dropdown menus

- Premium enterprise feel

The final result must look like a high-end industrial logistics SaaS platform.
